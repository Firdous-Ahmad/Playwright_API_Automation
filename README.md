# Playwright API Automation Framework

A C# API automation framework built using Microsoft Playwright and NUnit.

## Tech Stack
- C#
- .NET 10
- Playwright API Testing
- NUnit
- Git and GitHub
- GitHub Actions

## Features
- Reusable API client
- GET, POST, PUT, PATCH and DELETE support
- Request and response validation
- JSON serialization and deserialization
- Automated CI pipeline using GitHub Actions

## Test Execution

Run the tests locally using:

```bash
dotnet test
```

## CI Pipeline

GitHub Actions automatically restores dependencies, builds the solution, executes API tests, and uploads test results.
